# Tech Stack

## Frontend

- **Framework:** Vue 3
- **Lenguaje:** TypeScript
- **Build Tool:** Vite
- **Estilos:** Tailwind CSS
- **Enrutador:** Vue Router
- **Gestión de Estado:** Pinia
- **Peticiones HTTP:** Axios
- **Testing:** Vitest
- **Componentes UI:** Headless UI, Heroicons
- **Notificaciones:** Vue Toastification
- **Imágenes:** browser-image-compression
- **Servicios Backend:** Firebase
- **Email:** EmailJS

## Backend

- **Framework:** FastAPI
- **Lenguaje:** Python
- **Base de Datos:** PostgreSQL (producción), SQLite (desarrollo)
- **ORM:** SQLModel
- **Migraciones:** Alembic
- **Autenticación:** Firebase Auth, JWT
- **Validación:** Pydantic (usado por SQLModel)
- **Testing:** Pytest
