🔐 Authentication Test

Para probar endpoints protegidos, necesitas un Firebase JWT token:

📋 Cómo obtener el token:
1. Ve a https://m-vintage-test.web.app
2. Inicia sesión con tu cuenta admin
3. Abre Developer Tools (F12) → Console
4. Pega: firebase.auth().currentUser.getIdToken().then(t => {console.log(t); navigator.clipboard.writeText(t)})
5. El token se copiará al clipboard automáticamente
